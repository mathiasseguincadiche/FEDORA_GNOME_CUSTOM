# GNOME / Nautilus — intégration

L'objectif n'est pas de copier le thème Ubuntu mais d'obtenir la même sensation de cohérence fonctionnelle.

Le profil installe Nautilus, File Roller, GVfs SMB/MTP/caméra/FUSE, Sushi, les portails GNOME, GNOME Terminal et son extension Nautilus. RPM Fusion apporte FFmpeg/GStreamer et `ffmpegthumbnailer` lorsque la politique codecs est activée.

Les réglages de rendu de police, le scaling, VRR/HDR et les options expérimentales Mutter restent aux valeurs Fedora/GNOME par défaut tant qu'une correction n'est pas justifiée. Les extensions GNOME tierces sont désactivées par défaut afin de réduire les variables lors d'un crash Shell/Mutter.
